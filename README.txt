МОЙ ГОД — личный план

Быстрый просмотр: откройте index.html в браузере компьютера.
Для установки на iPhone разместите содержимое этой папки на статическом HTTPS-хостинге (все пять файлов приложения в одной папке). Откройте полученный URL в Safari, нажмите «Поделиться» → «На экран Домой». После первого открытия и загрузки ресурсов приложение может работать офлайн.

Данные хранятся локально. Нет аккаунта, облачной синхронизации, уведомлений или встроенной аналитики. Экспорт и импорт резервной копии доступны в настройках. Не удаляйте данные браузера без копии. Данные в разных браузерах и по разным URL могут отличаться.

Результат — числовой показатель (в том числе уменьшающийся). Действие — отметка выполнения. Привычка — число дней с отметкой за день/неделю/месяц; будущие дни нельзя отметить. Для просмотра истории меняйте дату. В обзоре считаются завершенные результаты и действия; привычки показываются отдельно.
